# Seed catalog preview study (synthetic study record)

Can a new instruction improve both the accuracy of a seed import preview and the explanation a catalog volunteer sees? Promote only if there is a matched improvement versus prior, no regressions and no unscored required checks. No effect on planting, germination, or any live catalog was tested. Candidate Pi 1.5.2 / Harbor 0.26.0; openai-codex/gpt-6.2-sol medium, 10 turns / 300 s. Three repeats per condition, one fixed case. Configured input: CSV plus local sandbox recorder. Stand-ins: the recorder takes the place of the real catalog and does not upload anything. Native Pi, file reads and invocation of the recorder were real in this fictional trial.

Prior instruction: Preview catalog imports before submitting them.
Revised instruction: Preview catalog imports and tell the volunteer which lots were skipped and why.

Preview check (code, preview.json emitted by the local recorder): expected preview flag true, accepted keys exactly {A17, B23} with no duplicates, skipped keys exactly {C09}. Pass only if all three predicates hold. Does not grade explanation and does not inspect whether a skipped row's reason is correct. Calibration: exact expected record passes; identical sets with duplicate B23 fails; reordered keys pass. Three of three expected.

Explanation check (model; final reply only, compared with the small reference answer C09 is skipped because the lot is retired; exact IDs, no condition/candidate labels). Rating met only if C09 and the retired-lot reason are linked AND the note doesn't claim a submission occurred; missing if ID or reason is absent; contradicted if it gives a wrong reason or claims a submission; uncertain if evidence is too ambiguous to decide. Operative r1 judge: openai-codex/gpt-6.1-terra medium, prompt J1; corrected: same model xhigh, prompt J2. r2 and r3 used J1 medium. Corrected prompt makes equivalent wording “no longer in the catalog” acceptable when linked to C09. Valid missing/contradicted/uncertain count as scored non-passes. Invalid JSON gets no semantic score, not a zero; known code score is kept. One qualifying final answer is not evidence against false-positive receipt checks. Calibration J1: explicit retired met, omitted reason missing, synonym missing (mismatch). J2: explicit retired met, omitted reason missing, synonym met, false upload contradicted (4/4 expected). This small calibration did not cover contradictory multi-lot replies.
