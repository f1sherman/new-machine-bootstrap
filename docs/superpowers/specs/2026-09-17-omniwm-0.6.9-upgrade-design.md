# OmniWM 0.6.9 Upgrade Design

Status: Self-approved

## Goal

Upgrade the laptop-only OmniWM installation from v0.6.8 to v0.6.9.
The release includes scratchpad, lifecycle, navigation, and window parking fixes.

## Non-goals

- Change OmniWM settings, shortcuts, or workspace rules.
- Deploy or restart OmniWM during this pull request.
- Bypass the repository's seven-day release-age policy.

## Assumptions

- The upstream v0.6.9 release is stable and more than seven days old.
- The existing exact-host gate remains the deployment boundary.
- The existing staged version and code-signature checks remain sufficient.

## Approach

Update the Renovate-managed version pin in `vars/tool_versions.yml`.
Keep all install and lifecycle logic unchanged.

### Alternatives

1. **Recommended: update only the version pin.** This follows the existing
   dependency pattern and keeps the diff small.
2. Pin the release checksum too. This adds a new integrity contract and is out
   of scope for a routine upgrade.
3. Install the release manually. This would bypass repository management and
   violate project policy.

## Verification

Run the repository's focused configuration tests, Ansible syntax check, and diff
check. Do not provision until the user approves live deployment.

## Rollout

Merge the pull request first. Provision the target laptop only after explicit
user approval.
