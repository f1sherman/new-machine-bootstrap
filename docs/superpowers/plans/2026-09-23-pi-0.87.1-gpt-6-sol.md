> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install Pi 0.87.1 so new OpenAI Codex sessions can select GPT-6 Sol.

**Architecture:** Update the existing authoritative Pi version pin. Deploy from
the feature worktree with a process-scoped Aube age exception for the named Pi
package family so the normal managed policy remains unchanged.

**Tech Stack:** Ansible YAML, mise, Aube, Pi CLI

**Spec:** `docs/superpowers/specs/2026-09-23-pi-0.87.1-gpt-6-sol-design.md`

- Pin Pi to exactly `0.87.1`.
- Keep the permanent 24-hour release-age policy unchanged.
- Scope the temporary bypass to the named Pi first-party package family for one
  provisioning process.

- Do not send a paid model request.
- Do not retain a static version-string test.
