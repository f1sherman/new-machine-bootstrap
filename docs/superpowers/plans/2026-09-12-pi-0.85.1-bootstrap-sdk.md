**Goal:** Install Pi 0.85.1 so PR monitor worker bootstrap can load the Pi SDK.

**Architecture:** Keep the existing mise provisioning path and change only its managed Pi version. Verify the installed CLI and SDK after provisioning instead of adding a static configuration test.

**Tech Stack:** Ansible, YAML, mise, Node.js

**Spec:** `docs/superpowers/specs/2026-09-12-pi-0.85.1-bootstrap-sdk-design.md`
