# Setup pstack

Use this entry only when the user explicitly invokes `setup-pstack`.

1. Read the shared [adapter](../pstack/ADAPTER.md) in full.
2. Read [MODEL-SETUP.md](../pstack/MODEL-SETUP.md) and follow its native model discovery, budget, recommendation, confirmation and machine-local save procedure.
3. Keep these choices in the local runtime profile. This command does not install credentials, edit managed skills, or configure another machine.
